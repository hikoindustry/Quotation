# HIKO Quotation Studio

Single-file quotation generator for HIKO's team.

- Hardware + Wardrobe Accessories 2026 catalogue data included.
- Catalogue rates are pre-filled and editable as Quoted Rate.
- Quantity and percentage discount supported.
- Clean A4 print/PDF quotation layout.
- HIKO logo embedded in the HTML.
- Designed to work on desktop and mobile.
